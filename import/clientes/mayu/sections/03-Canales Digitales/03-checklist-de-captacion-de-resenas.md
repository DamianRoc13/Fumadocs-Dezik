# Checklist de captación de reseñas

Google My Business · Proceso operativo

Abril 2026

Mayu tiene 5.0★ con 118 reseñas — el activo digital más valioso de la marca. Cada reseña nueva refuerza ese número, genera contenido para redes y cierra la duda de confianza del prospecto nuevo. Meta: +30 reseñas en 90 días.

---

**01 · Configuración inicial**

Hacer una sola vez — en los primeros 3 días

---

| □ | Obtener el link directo de reseñas de Google |
| --- | --- |
|  | *Google Maps → buscar "MAYU Ecuador" → clic en "Escribir reseña" → copiar esa URL* |

| □ | Crear alias corto del link |
| --- | --- |
|  | *Ej: mayuecuador.com/resena — redirige directamente al formulario de Google* |

| □ | Generar QR con el link corto |
| --- | --- |
|  | *qr-code-generator.com o similar — descargar en alta resolución (PNG, mínimo 1000px)* |

| □ | Imprimir tarjeta con QR para entregar en caja |
| --- | --- |
|  | *Tamaño tarjeta de visita. Texto sugerido: "¿Te ayudamos bien hoy? Cuéntanoslo en Google" + QR* |

| □ | Guardar el link como respuesta rápida en WhatsApp Business |
| --- | --- |
|  | *Tecla /resena → envía el link directamente sin escribirlo cada vez* |

| □ | Crear carpeta "Testimonios aprobados" para archivar reseñas destacadas |
| --- | --- |
|  | *Google Drive o carpeta local — cada reseña guardada es contenido listo para reciclar en Instagram* |

| □ | Crear hoja de seguimiento semanal |
| --- | --- |
|  | *Una hoja de cálculo simple: fecha + total de reseñas acumuladas. Para medir avance hacia la meta de +30 en 90 días* |

**02 · Momentos de pedido**

Ejecutar en cada caso que corresponda — sin excepción

---

| □ | Al cerrar consulta presencial satisfactoria: pedir de viva voz y entregar tarjeta con QR |
| --- | --- |
|  | *"Si te fue útil la consulta, nos ayudaría mucho que lo cuentes en Google — tarda 30 segundos." Entregar tarjeta.* |

| □ | A los 7 días post-compra: incluir pedido al final del mensaje /seguimiento de WhatsApp |
| --- | --- |
|  | *Añadir al final: "Si el tratamiento te está funcionando, una reseña en Google nos ayuda mucho a llegar a más personas como tú." + link /resena* |

| □ | Cuando un paciente manda mensaje positivo espontáneo por WhatsApp: responder con calidez y pedir reseña |
| --- | --- |
|  | *"¿Te animarías a compartirlo en Google? Tu experiencia puede orientar a alguien que está buscando lo mismo." + link /resena* |

**03 · Lo que nunca hay que hacer**

Evitar siempre — estas prácticas dañan el perfil y la relación con el paciente

---

| □ | Nunca pedir "deja 5 estrellas" — viola las políticas de Google y suena forzado |
| --- | --- |
|  | *El encuadre correcto siempre es en términos de ayudar a otros, no de puntaje* |

| □ | Nunca pedir reseña a un paciente que no ha tenido una buena experiencia |
| --- | --- |
|  | *Primero resolver el problema, después — si corresponde — invitar a compartir la experiencia* |

| □ | No dejar reseñas sin respuesta — responder todas en máximo 48 horas |
| --- | --- |
|  | *Cada respuesta es visible para los próximos visitantes del perfil. El silencio también comunica.* |

**04 · Reciclaje de reseñas**

Proceso mensual — convertir una reseña en tres puntos de contacto

---

| □ | Identificar la mejor reseña del mes y guardarla en la carpeta "Testimonios aprobados" |
| --- | --- |

| □ | Publicar el testimonio del mes en Instagram como carrusel o story |
| --- | --- |
|  | *Con nombre y ciudad del paciente si da permiso. Hace el testimonio más creíble y específico.* |

| □ | Actualizar la sección de testimonios del sitio web trimestralmente |
| --- | --- |
|  | *Rotar las reseñas más recientes y representativas en la home o página de Farmacia* |

**05 · Revisión semanal**

Cada lunes — 5 minutos máximo

---

| □ | Contar reseñas nuevas llegadas durante la semana |
| --- | --- |
|  | *Meta orientativa: 2-3 por semana para alcanzar +30 en 90 días* |

| □ | Responder todas las reseñas pendientes en Google (positivas y negativas) |
| --- | --- |

| □ | Registrar el total acumulado en la hoja de seguimiento |
| --- | --- |
|  | *Fecha + número total de reseñas. En 4 semanas ya se ve si el ritmo es suficiente para la meta.* |

Recordatorio: el 82% de los no-conocedores de Mayu dijo que la recomendación médica y los certificados de laboratorio son los factores de confianza más importantes. Las reseñas en Google son la versión digital de esa recomendación. Cada reseña nueva reduce la fricción del próximo paciente para dar el primer paso.
