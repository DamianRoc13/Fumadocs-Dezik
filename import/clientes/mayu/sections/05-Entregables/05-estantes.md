# Estantes

**Sistema gráfico para exhibición en punto de venta**
Se desarrolló una propuesta gráfica para los estantes y exhibidores de Mayu, pensada para organizar visualmente el espacio, reforzar la identidad de marca y acompañar la presentación de productos dentro del punto de venta. La composición integra mensajes institucionales, beneficios de producto y elementos visuales alineados con el universo de ciencia, naturaleza y bienestar.

![MAY_MOCKUP_STAND_GENERAL.jpg](MAYU_ESTANTES_01.webp)

La propuesta incluye piezas gráficas aplicadas a distintos soportes del punto de venta, como paneles laterales, fondos de exhibición, módulos informativos y superficies frontales. Esto permite construir una presencia visual unificada, manteniendo una estética limpia, profesional y fácil de identificar.

Dentro del sistema se incorporan mensajes sobre fórmulas magistrales, respaldo científico, ingredientes naturales y beneficios funcionales, permitiendo que el mobiliario también cumpla una función informativa además de estética.

**La propuesta gráfica para estantes convierte la exhibición de productos en una experiencia más ordenada, informativa y alineada con la identidad visual de Mayu.**
