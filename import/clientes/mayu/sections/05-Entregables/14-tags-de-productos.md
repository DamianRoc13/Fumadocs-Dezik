# Tags de productos

**Identificadores visuales para categorías en tienda**
Se diseñó una propuesta de tags de productos para Mayu, pensada para identificar de forma clara las diferentes categorías dentro del punto de venta. Estas piezas funcionan como señalizadores pequeños y elegantes, ayudando a organizar la exhibición y mejorar la lectura de los productos en estantes o mesas.

![image.png](MAYU_TAGS-DE-PRODUCTOS_01.webp)

Los tags utilizan una estructura tipo tarjeta plegable, lo que permite colocarlos directamente sobre superficies, estantes o zonas de exhibición. Su diseño combina el color institucional, una tipografía clara y detalles gráficos sutiles que aportan identidad sin distraer del producto.

El diseño mantiene una estética minimalista y sobria, permitiendo que cada categoría se identifique de forma rápida y ordenada. Además, el formato puede adaptarse fácilmente a diferentes nombres de productos o líneas comerciales.
