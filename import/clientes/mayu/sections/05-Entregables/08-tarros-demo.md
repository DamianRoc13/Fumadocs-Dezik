# Tarros Demo

**Sistema visual para envases magistrales**
Se desarrolló una propuesta demo de envases para Mayu, pensada para visualizar cómo se verían las fórmulas magistrales aplicadas en tarros de vidrio ámbar con etiquetas diferenciadas por color. El sistema busca mantener una estética limpia, profesional y natural, facilitando la identificación de cada fórmula según su función o protocolo.

![MAY_DEMO_01.png](MAYU_TARROS-DEMO_01.webp)

Cada tarro utiliza un color específico para diferenciar visualmente las líneas de producto, como inmunidad, recuperación, dolor e inflamación, digestión, estrés y sueño. Esta codificación permite organizar mejor las fórmulas y hacer que el producto sea más fácil de reconocer para el cliente.

![MAY_DEMO_02.png](MAYU_TARROS-DEMO_02.webp)

El uso de vidrio ámbar aporta una percepción más profesional, farmacéutica y natural, mientras que las etiquetas mantienen una composición limpia con información clara, jerarquizada y alineada con la identidad de Mayu.

![MAY_DEMO_03.png](MAYU_TARROS-DEMO_03.webp)

Los tarros demo muestran cómo el sistema gráfico de Mayu puede aplicarse a una línea de productos clara, ordenada y visualmente diferenciada, manteniendo una identidad profesional y coherente.
