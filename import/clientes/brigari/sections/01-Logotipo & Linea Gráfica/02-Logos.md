# 02 - Logos

La identidad de **BRIGARI** se construye a partir de un sistema visual versátil y con carácter. Su logotipo e isotipo reflejan la esencia de una marca que guía al usuario hacia distintos destinos gastronómicos, conectando restaurantes, sabores y experiencias dentro de una misma ruta visual.

Las diferentes versiones del logo permiten que la marca se adapte con coherencia a medios digitales, piezas editoriales físicas, contenido gastronómico, señalética, experiencias y alianzas con restaurantes. Cada aplicación mantiene una imagen sofisticada, clara y reconocible, reforzando el propósito de **BRIGARI;** descubrir la buena comida con criterio, estilo y confianza.

## Variaciones

El sistema de identidad de **BRIGARI** contempla distintas versiones del logotipo para responder con flexibilidad a diferentes formatos y escalas. La marca puede utilizarse en composición horizontal, vertical o centrada, permitiendo adaptarse correctamente a piezas editoriales, plataformas digitales, aplicaciones impresas y espacios de comunicación más amplios.

El isotipo funciona como una versión reducida y de alto reconocimiento, ideal para usos donde el espacio es limitado o donde se requiere una presencia más simbólica. De igual manera, la “B” simplificada permite una aplicación más sutil, funcionando como firma gráfica, detalle visual o recurso de apoyo dentro del sistema.

Estas variaciones permiten que la marca mantenga coherencia sin depender de una sola estructura. El juego entre logotipo completo, isotipo y versiones simplificadas aporta versatilidad, jerarquía y control visual, asegurando que la marca conserve su identidad en cada punto de contacto.
