# Cromática

En nuestro proceso de diseño y creación de identidad visual, seleccionamos cuidadosamente una paleta de colores para representar la marca. Para garantizar la correcta reproducción de estos colores tanto en plataformas digitales como en impresiones físicas, es crucial comprender los diferentes sistemas de códigos de colores y su uso.

**Códigos de Color y Sus Diferencias:**

1. **HEX**: El código Hex (o hexadecimal) es el formato más utilizado para el diseño digital. Se compone de seis caracteres, representando los valores de los colores en formato RGB (Rojo, Verde, Azul). Por ejemplo, el color principal de nuestra marca, el verde motivacional, tiene el código **#D6F800**.
2. **CMYK**: El sistema CMYK es utilizado en la impresión. Los valores en este sistema se representan en porcentajes de Cian (C), Magenta (M), Amarillo (Y) y Negro (K). Estos porcentajes indican la cantidad de tinta utilizada en la impresión. Para el verde motivacional, el valor CMYK es **22,00, 100,00**, lo que significa un 22% de Cian y un 100% de Magenta, con 0% de Negro.
3. **RGB**: Este sistema se utiliza principalmente en pantallas y dispositivos electrónicos. RGB se basa en la combinación de tres colores primarios (Rojo, Verde, Azul). Los valores de **RGB** para el color verde son **214, 248, 0**, lo que indica la intensidad de cada color primario en la pantalla.

## Colores Pantone

Los colores **Pantone** son un sistema estándar de colores utilizado en la industria de la impresión. Cada color Pantone está identificado por un número único, lo que garantiza que el color se reproduzca de manera precisa y consistente en diferentes tipos de impresoras y materiales.

**Diferencia entre Pantone Coated (C) y Uncoated (U):**

- **Pantone C (Coated)**: Este es el sistema utilizado para papeles recubiertos, como el papel brillante o estucado. Los colores Pantone C tienen un acabado más vibrante y saturado, ya que el papel recubierto refleja más luz.
- **Pantone U (Uncoated)**: Este sistema está diseñado para papeles sin recubrimiento, como papeles mate. Los colores en este formato pueden lucir más apagados debido a la menor reflexión de luz en el papel.

Para asegurar que los colores de nuestra marca tengan una apariencia coherente en cualquier formato, hemos elegido los colores **Pantone 381C** para el verde y **Pantone Black C** para el color negro.

**Uso del Gris en Impresión:**

El color gris que utilizamos tiene un valor similar al **Pantone Black C**, pero con una saturación reducida (por ejemplo, un 10%). Esto permite que el gris tenga una apariencia más suave y adecuada para su reproducción en papel recubierto, asegurando que el diseño no pierda calidad en la impresión.
