# Rol estratégico de cada canal en el ecosistema

El ecosistema digital de Mayu debe operar con lógica de embudo: cada canal cumple un rol específico y se conecta con los demás. No todos los canales hacen lo mismo. La dispersión actual (mismo contenido en todos los canales, sin estrategia diferenciada) es uno de los problemas a resolver.

![ESTRATEGIA_12.png](/MAYU_ROL-ESTRATEGICO-DE-CADA-CANAL-EN-EL-ECOSISTEM_01.webp)

| **Canal** | **Rol en el ecosistema** |
| --- | --- |
| **Google (SEO + GMB)** | ADQUISICIÓN. Captura demanda informacional y navegacional. Puerta de entrada para quien no conoce Mayu pero tiene un problema de salud. GMB valida para quien ya oyó hablar de la marca. |
| **Instagram** | DESCUBRIMIENTO + EDUCACIÓN + COMUNIDAD B2C. Canal de mayor crecimiento y el más relevante para el perfil demográfico dominante (mujeres 25–44). Aquí se construye autoridad y confianza. |
| **Facebook** | RETARGETING + PAID ACQUISITION. No tiene potencial orgánico significativo. Debe amplificar a audiencias similares a los mejores clientes actuales y hacer remarketing a visitantes web. |
| **Mensajería (IG DM + WhatsApp)** | CONVERSIÓN. El momento donde el interés se transforma en consulta o compra. Debe funcionar como extensión digital de la asesoría gratuita presencial. |
| **Sitio Web** | CONVERSIÓN + CREDIBILIDAD. Punto de aterrizaje del tráfico pagado y orgánico. Debe comunicar el diferencial en el primer scroll y tener CTA claro hacia consulta o compra. |
| **Blog / Contenido SEO** | CAPTURA DE DEMANDA INFORMACIONAL. Artículos orientados a queries de problemas de salud posicionan a Mayu antes de que el usuario conozca la marca. Mayor potencial a mediano plazo. |
| **Email Marketing** | FIDELIZACIÓN + REACTIVACIÓN. Una vez que existe base de datos, permite comunicación segmentada B2C (educación + ofertas) y B2B (formación + novedades). Requiere plataforma. |
| **Tarjetas de fidelización** | RETENCIÓN + DATA COLLECTION. Activo existente con potencial no explotado. Ver sección dedicada (8.3) para detalle estratégico. |
| **Google My Business** | VALIDACIÓN SOCIAL + CONVERSIÓN LOCAL. Las 118 reseñas 5.0★ son el cierre de confianza para usuarios indecisos. Mantener activo y sistematizar captación. |

## 5.1 Rol estratégico de las tarjetas de fidelización digitales

![ESTRATEGIA_16.png](/MAYU_ROL-ESTRATEGICO-DE-CADA-CANAL-EN-EL-ECOSISTEM_02.webp)

- **Función 1 — Retención y recompra:** la tarjeta incentiva una segunda y tercera compra en un modelo donde el ticket promedio es $45 y el producto dura 1–1.5 meses. Un ciclo de recompra bien estructurado puede convertir compradores ocasionales en pacientes recurrentes.
- **Función 2 — Notificaciones instaneas:** la tarjeta puede enviar notificaciones cortas con contenido promocional, de felicitaciones o informativos a los clientes.
- **Función 3 — Datos para segmentación:** si la tarjeta registra comportamiento de compra (frecuencia, productos, valor), esos datos permiten personalizar comunicaciones futuras (recordatorios de recarga, promociones, seguimiento clínico).
- **Función 4 — Programa de referidos:** la tarjeta puede ser el vehículo del programa de referidos estructurado. Cada cliente puede “invitar” a un nuevo paciente y obtener beneficios en su tarjeta.

**GAP · INFORMACIÓN INSUFICIENTE**

No se tienen datos sobre el número de tarjetas activas actualmente, la plataforma que las gestiona, las reglas de acumulación/canje, ni métricas de uso. Antes de integrar la tarjeta al ecosistema digital, se requiere un diagnóstico del estado actual del programa.
